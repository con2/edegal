# Prisma 8 RC spikes (2026-09-10)

Findings that shaped the implementation; re-verify when bumping the RC.

| #     | Question                       | Outcome                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ----- | ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| S1    | RC toolchain end to end        | `prisma@8.0.0-rc.13` CLI + `@prisma/orm-postgres@8.0.0-rc.9` runtime emit, plan, migrate and query fine. Contract JSON import needs `with { type: "json" }`.                                                                                                                                                                                                                                                                                                                                 |
| S2/S3 | Legacy load and resolution     | Hand-written SQL on the shared `pg` pool: one `UNION ALL` probe over the five `path` columns, 3-4 statements per legacy album.                                                                                                                                                                                                                                                                                                                                                               |
| S4    | Coexistence with Django tables | `db init`/`db migrate` touch only contract tables. `db verify` tolerates the 20 unmanaged tables (fails only with `--strict`). **`db update` plans `DROP TABLE` for every unmanaged table** – never run it here.                                                                                                                                                                                                                                                                             |
| S5    | Client navigation              | `history.pushState/replaceState` update `usePathname()` without a server request; `router.replace` would refetch the whole album.                                                                                                                                                                                                                                                                                                                                                            |
| S7    | Auth without adapter           | next-auth v4 JWT sessions; user row upserted in the `jwt` callback with `conflictOn`.                                                                                                                                                                                                                                                                                                                                                                                                        |
| S8    | Native enums                   | `native_enum Name { a = "a" @@map("type") }` + field type `pg.enum(Name)` creates `CREATE TYPE ... AS ENUM`. Plain `enum` blocks are text columns with CHECK constraints. Default is a string literal: `@default("public")`.                                                                                                                                                                                                                                                                 |
| S9    | Ids and temporal types         | `@default(uuid(7))` generates UUIDv7 ids in the runtime (production runs PostgreSQL 17, which has no `uuidv7()`; `dbgenerated("uuidv7()")` was tried and reverted). Ids for rows inserted with raw SQL must be supplied by the caller. `Timestamptz`/`Date` decode to Temporal objects and need a polyfill; the `TimestamptzString`/`DateString` spellings return text (`2026-09-10 19:59:34.726+03`, normalised in `src/lib/time.ts`). `temporal.updatedAtString()` maintains `updated_at`. |

Other RC facts: `@types/pg`/`pg` must match the runtime's pinned versions (8.20.4 / 8.22.0) or the `pg:` option fails to type-check; `.all()` results are single-consumption; `db.raw.sql` exists but the legacy module uses `pg` directly.

Standalone server gotchas: never set the `HOSTNAME` env var (see Dockerfile comment; with it set every page 307-loops because the locale rewrite becomes cross-host), and give `MEDIA_ROOT` an absolute path because `server.js` changes the working directory.

Image size: the `prisma` CLI depends on Prisma's cloud deployment tooling (`@prisma/composer*`, `alchemy`, `workerd`, ~1 GB). `src/bin/migrate.mjs` mounts only `ormCommandFamily` from `@prisma/orm-toolchain` on `@prisma/cli-engine`'s `createCli`, which the migrator image installs alone (50 MB). `@prisma/cli-engine` and `@prisma/orm-toolchain` are pinned in package.json to the versions the installed `prisma`/`@prisma/orm-postgres` resolve to; keep them in step when bumping.

Downloads (round 2): album zips are streamed on demand by `/api/zip/<album path>` with `yazl` in store mode (README.txt first, `slug.jpg` entries like the legacy zips); nothing is stored and authorization is the album's own. The legacy pre-built zips under `/media/downloads/` are no longer linked but still served by nginx. Conditions of use for v4 albums live in the reusable `v4_terms` table and are inherited from the nearest ancestor album.
